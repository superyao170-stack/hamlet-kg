# 面向 Knowledge-Based Systems 的实验路线

> 历史方案：当前投稿目标已调整为 KAIS，交易检测主线见 [当前 README](../README.md) 与 [KAIS 研究协议](kais_research_protocol.md)。本文件保留旧案例检索与规则编译实验设想，不代表当前主任务或实现状态。

## 1. 论文定位

拟定英文题目：

> LLM-Augmented Multi-Granular Event Knowledge Graphs for Risk-Event Reasoning and Hierarchical Case Retrieval

研究对象是通用的多粒度事件知识表示，反洗钱作为主要验证场景。系统实现不是独立贡献，只用于验证形式模型和算法。

## 2. 研究问题

- RQ1：原子事件本体与形式约束能否提高 LLM 规则编译的语法、类型和执行正确率？
- RQ2：风险事件作为中间语义层，能否比原子事件直接匹配和风险标签直接匹配获得更好的案例检索效果？
- RQ3：原子组成感知的风险事件软对齐是否能提高缺失、噪声和事件数量不一致条件下的鲁棒性？
- RQ4：受限模式语言能否在保持表达能力的同时降低在线图匹配开销？

## 3. 数据

### 主数据

- AMLSim 或 IBM synthetic AML transactions；
- 从交易标签和已知模式构造案例，不把标签输入模型；
- 按完整模式实例和时间切分，禁止将同一资金链拆到训练集和测试集。

### 外部验证

- Elliptic2 或另一个公开交易子图数据集；
- 用于验证图表示和案例检索的跨数据泛化，不强行用于自然语言规则编译。

### 规则—模式数据

- 目标规模 300—500 条自然语言规则；
- 每条规则对应标准 DSL 和标准执行结果；
- 至少两名标注者独立标注；
- 报告 Cohen's kappa 或 Krippendorff's alpha；
- 测试集人工冻结，不用LLM生成测试标签。

## 4. 对比方法

### 规则编译

- Zero-shot LLM；
- Few-shot LLM；
- LLM + 原子事件本体；
- LLM + 本体 + 语法校验；
- LLM + 本体 + 校验反馈修正。

### 风险事件识别

- 人工规则；
- LLM直接风险分类；
- 原子事件统计特征 + LightGBM；
- 原子事件图编码器；
- 本文形式模式匹配；
- 形式模式与学习模型融合。

### 案例检索

- 风险类型标签 Jaccard；
- 原子事件袋相似度；
- 原子事件图 GED；
- Graph2Vec/Sub2Vec；
- 风险事件图 GED；
- 风险事件贪心匹配；
- 本文原子组成感知的风险事件最优传输对齐。

## 5. 指标

### 规则编译

- JSON/DSL 语法正确率；
- 类型正确率；
- 可执行率；
- 与金标准模式的结构准确率；
- 执行结果等价率；
- 平均修正轮数和 Token 成本。

### 风险事件识别

- Precision、Recall、F1；
- PR-AUC；
- 模式级 Macro-F1；
- 未见模式泛化性能。

### 案例检索

- Recall@1/5/10；
- MRR；
- NDCG@5/10；
- MAP；
- 人工案例相似度与模型分数的相关性。

### 效率

- 索引构建时间；
- 单案例物化时间；
- 单查询延迟；
- 峰值内存；
- LLM调用数和Token数。

## 6. 消融实验

- 去掉风险事件层，直接匹配原子图；
- 去掉风险事件内部原子组成；
- 去掉角色结构；
- 去掉时序特征；
- 去掉风险事件关系；
- 最优传输改为贪心对齐；
- 固定权重与验证集学习权重；
- 去掉 DSL 校验反馈；
- 不同 LLM 和不同提示示例数量。

## 7. 鲁棒性实验

- 随机删除 10%、20%、30% 原子事件；
- 时间戳扰动；
- 金额扰动；
- 动作类型噪声；
- 风险事件数量不一致；
- 未见风险模式；
- 类别不平衡变化。

## 8. 统计与复现

- 至少五个随机种子；
- 报告均值、标准差和置信区间；
- 对主要比较做显著性检验和效应量分析；
- 冻结数据划分和超参数搜索空间；
- 公布代码、配置、模式定义和非受限数据处理脚本；
- 对失败案例做类型化错误分析。

## 9. 进入投稿前的门槛

- 至少一个形式化定义体系和一项非平凡性质证明；
- 至少两个数据来源或清晰的跨域验证；
- 至少一个强图学习基线；
- 完整消融、鲁棒性和复杂度实验；
- 主要结果具有统计显著性；
- 说明 LLM 在方法中不可被普通模板完全替代的原因；
- 说明风险事件层相对于直接原子图匹配的必要性。
