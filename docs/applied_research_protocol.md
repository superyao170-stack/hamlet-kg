# 面向专业硕士论文的算法—应用路线

## 论文定位

本项目不再把“结构化数据生成分析文本，再由 LLM 抽取五层图谱”作为论文主链路。新的定位是：结构化交易被确定性地映射为原子事件图，图算法将有界的原子事件组合物化为风险事件，案例检索在风险事件图层进行；LLM 只负责把自然语言规则编译成候选 DSL，并且不能绕过校验与图匹配直接输出正式风险事件。

这使论文的贡献可以被拆成可评价的算法模块，而不是系统功能清单。

## 三个算法模块

### A1：有界时间窗的风险事件匹配（CP-REM）

输入是按时间排序的原子事件流和风险模式 DSL。算法维护主体、对手方、动作类型与时间窗索引，增量识别 fan-in、fan-out、pass-through、cycle 等风险事件。建议改进点是共享前缀、窗口过期删除、金额守恒约束和重叠事件抑制。

比较对象：朴素规则扫描、NetworkX VF2、无剪枝滑窗、CP-REM 完整版本。

评价：事件级 Precision、Recall、F1，运行时间，峰值内存；并报告窗口宽度、阈值与去重策略的敏感性。

实现状态：已实现第一版索引化滑动窗口、多个时间分离实例物化、重复窗口删除和重叠窗口抑制；尚需加入真正的流式增量状态、cycle/relay 多跳算子和事件级 ground truth。

### A2：模式索引与候选剪枝

先利用动作类型、中心角色、入出度下界、时间跨度和金额区间生成候选，再进行精确约束验证。该模块的论文价值是把通用子图匹配转化为面向 AML 模式的有界搜索。

比较对象：VF2、仅度数剪枝、仅时间剪枝、组合索引。

评价：候选缩减率、匹配加速比、命中一致性和不同图规模下的增长曲线。

实现状态：原子事件匹配已使用 `(action_type, role, entity)` 倒排索引和子句计数/不同角色剪枝；案例检索已使用风险类型倒排索引与粗排候选池。AMLSim 5K 实跑中，从 20,000 个实体缩减到 19 个候选中心实体。

### A3：原子组成增强的风险事件图对齐

风险事件作为案例匹配单元，原子事件只用于构造风险事件属性与内部结构。先计算风险事件对的语义、角色、时间和金额组成代价，再用 Sinkhorn 或 Fused Gromov–Wasserstein 对齐两张风险事件图。

比较对象：字符串/集合相似度、Hungarian、Sinkhorn、FGW、HAMLET 分层模型。

评价：Recall@K、MRR、NDCG@K、运行时间以及去掉原子组成、风险关系和时间项的消融结果。

实现状态：已实现依赖无关的熵正则 FGW 风格交替对齐，同时保留原分层 Sinkhorn 和 POT FGW 参考结果。当前示例只验证算法行为，尚不足以证明统计优势。

## LLM 的边界

LLM 不参与交易事实生成、不预测最终风险标签，也不替代图匹配。它只将自然语言规则生成候选 DSL；候选规则必须经过语法校验、类型校验、约束可满足性检查和固定测试集回归。论文应分别报告规则编译成功率与下游匹配效果，不能把两者混为一个端到端指标。

## 当前公开数据的使用方式

AMLSim 20K cycle、fan-in 和 combined 样本用于原子事件转换、风险模式识别、效率和消融实验。当前质量检查发现：异常金额与正常金额存在明显断层、重复交易高度有信息量、约一半欺诈节点缺少有效 `fraudStep`。因此：

- 不把金额阈值的高 F1 作为贡献结论；
- 主任务逐步从节点级代理评价升级到事件级模式评价；
- 增加金额扰动、重复记录去除和跨配置测试；
- 如条件允许，再使用第二个公开数据集或自行构造小规模人工事件标注集进行外部验证。

## 推荐论文结构

1. 绪论：银行现有流程的 LLM 依赖与不可复现问题；
2. 相关工作：事件知识图谱、AML 图模式、时序子图匹配、图最优传输；
3. 问题定义：原子事件、风险事件、风险事件图与相似案例检索；
4. 方法：A1、A2、A3 及复杂度分析；
5. 系统实现：数据适配、DSL、可解释输出与 LLM 可选接口；
6. 实验：公开数据、基线、主结果、效率、消融、鲁棒性；
7. 讨论：合成数据偏差、标签粒度、真实银行数据迁移；
8. 结论。

当前版本属于“可运行基线与实验脚手架”，尚不是已经达到 Knowledge-Based Systems 录用标准的完整结果。
